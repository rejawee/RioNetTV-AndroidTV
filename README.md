# RioNet TV — Android TV / Receiver

مشروع RioNet TV المخصص لأجهزة Android TV وGoogle TV والريسيفرات المبنية على Android.

النسخة الحالية: **v1.0.1 Proxy RC1**.

- Kotlin + Jetpack Compose for TV
- Media3 / ExoPlayer
- Xtream Codes + M3U
- دعم D-pad / Remote
- HTTP Proxy اختياري داخل التطبيق

> هذه نسخة اختبارية RC مخصصة لبناء APK تجريبي واختبار البروكسي والبث على جهاز تلفزيون/ريسيفر حقيقي.
